OpenAI 환경 설정

API 키 발급 · 결제·크레딧 · 문서 · Spring Boot .env 연동

Spring AI에서 OpenAI 모델을 쓰려면 Platform API Key와 결제(크레딧) 설정이 필요합니다. 키는 저장소에 올리지 말고 .env로 관리하고, application.yml에서 선택적으로 불러옵니다.

목차

  1. API 키 발급
  2. OpenAI 문서
  3. Spring Boot 프로젝트에 키 입력

1. API 키 발급

OpenAI Platform 에 로그인한 뒤 키를 발급합니다.

  1. 상단 톱니(설정) → API Keys → Create new secret key — 프로젝트는 default, 권한은 All 등 과정 안내에 맞게 선택
  2. Billing → Payment methods에서 카드 등록 후 크레딧 충전. Auto recharge는 반드시 꺼 두는 것을 권장합니다.

3. Spring Boot 프로젝트에 키 정보 입력

프로젝트 루트에 .env 파일을 만들고 키를 넣습니다. Git에 올릴 때는 .gitignore에 .env를 반드시 추가합니다.

OPEN_AI_KEY=sk-proj-TcdDCv
GEMINI_KEY=AIzaSyDkpW5sh1I

Spring Boot가 .env를 읽도록 application.yml(또는 프로필별 yml)에 다음을 둡니다.

spring:
  config:
    import: optional:file:.env[.properties]
