Ollama 환경 설정

Docker · Ollama 이미지·컨테이너 · LLaMA 3.2 로컬 모델 · API 동작 확인

로컬에서 LLM을 쓰기 위해 Docker로 Ollama 서버를 띄우고, 컨테이너 안에서 모델을 받아 localhost:11434로 호출합니다. Spring AI의 Ollama 연동 실습 전제가 되는 절차입니다.

목차

  1. Docker 설치
  2. Ollama 이미지 다운로드 및 컨테이너 실행
  3. LLaMA 3.2 모델 준비
  4. Ollama 및 llama3.2 접속 확인

1. Docker 설치

Docker — Get Docker — OS에 맞는 Docker Desktop(또는 Linux의 Docker Engine)을 설치합니다. 설치 후 터미널에서 docker version으로 클라이언트와 엔진이 모두 응답하는지 확인하세요.

설치 시 주의 사항
  • Windows: Docker Desktop은 보통 WSL 2 기반입니다. BIOS/UEFI에서 가상화(VT-x/AMD-V)가 켜져 있어야 하고, WSL2 설치·업데이트는 공식 가이드를 따릅니다.
  • 리소스: Docker Desktop → Settings → Resources에서 CPU·메모리·디스크를 할당합니다. Ollama·모델 이미지는 디스크와 RAM을 많이 사용합니다.
  • 포트: 다음 절에서 쓰는 11434 포트가 로컬의 다른 서비스와 겹치지 않는지 확인합니다.
  • 회사망·보안: 프록시/VPN/백신이 Docker Hub 접속이나 docker pull을 막을 수 있습니다. 필요하면 IT 정책에 맞게 설정합니다.
  • 관리자 권한: 설치·업데이트 시 관리자 권한이 필요할 수 있습니다.
문제 발생 시 해결 방안
  • docker를 찾을 수 없음 → Docker Desktop이 설치되어 있고 실행 중인지(시스템 트레이) 확인합니다.
  • Cannot connect to the Docker daemon → Docker Desktop을 완전히 종료 후 다시 실행하거나 PC 재부팅 후 재시도합니다.
  • port is already allocated → 11434를 쓰는 프로세스·컨테이너를 종료하거나, 다음 절의 docker run에서 호스트 포트만 다른 값(예: -p 11435:11434)으로 바꿉니다.
  • 이미지 pull 실패 → 네트워크·DNS·방화벽을 확인하고, 잠시 후 재시도하거나 Docker 공식 문서의 네트워크/프록시 항목을 참고합니다.
  • WSL 관련 오류(Windows) → Docker Desktop → Settings → Resources → WSL integration에서 배포판 연동을 켜고, wsl --update 등으로 환경을 점검합니다.

2. Ollama 이미지 다운로드 및 컨테이너 실행

Docker Desktop을 실행 후 명령 프롬프트에서 이미지를 받은 다음 컨테이너를 띄웁니다.
컨테이너 이름은 ollama-server, 포트는 11434로 맞춥니다.

docker pull ollama/ollama:latest
docker run -d --name ollama-server -p 11434:11434 ollama/ollama:latest

설치 후 Docker Desktop의 Containers에서 상태를 확인할 수 있습니다.

3. LLaMA 3.2 모델 준비

컨테이너 안에서 LLaMA 3.2 모델을 받습니다.

docker exec -it ollama-server ollama pull llama3.2

이후 Docker Desktop → Containers에서 해당 컨테이너를 중지·시작할 수 있습니다.

4. Ollama 및 llama3.2 접속 확인

1) Ollama API 태그 목록 - 명령 프롬프트에서 실행

curl http://localhost:11434/api/tags

2) llama3.2 생성 요청
Windows 명령 프롬프트

curl http://localhost:11434/api/generate ^
      -H "Content-Type: application/json" ^
      -d "{\"model\":\"llama3.2\",\"prompt\":\"Hello\",\"stream\":false}"

Mac / Linux (bash, zsh)

curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Hello",
  "stream": false
}'

로컬 LLM 환경에서 llama3.2 기반 호출이 가능한 상태입니다.
