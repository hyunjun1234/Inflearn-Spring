Chapter 2. Agentic Workflow Patterns (워크플로 패턴)


Workflow Description
1. Chain Workflow 설명
LLaMA → GPT → Gemini 순으로 한 단계의 출력이 다음 단계 입력이 되는 순차 체인입니다. 아이디어에서 키워드를 뽑고, 홍보 문구를 쓰고, 톤·번역을 다듬는 흐름을 한 API로 묶습니다.
동작 흐름
1 · LLaMA키워드 추출 · user(rawIdea)
↓
2 · GPT홍보 문구 · user(키워드)
↓
3 · Gemini검수·번역 · 이전 단계 출력
1) LLaMA — 키워드·핵심어 추출(경량 1차 정제)
2) GPT — 마케팅 카피·홍보 문구 생성
3) Gemini — 문맥 검수·품질 보정·다국어(번역) 처리
REST: POST /ch2/chain-workflow · prompt
2. Parallelization Workflow 설명
기술·시장·글로벌 관점을 동시에 뽑은 뒤, GPT가 한 장의 종합 리포트로 합칩니다. ParallelWorkflowService 기준 병렬 전체 대기 타임아웃은 약 130초이며, 예외·로깅을 포함한 실습용 구현입니다.
동작 흐름

CompletableFuture · FixedThreadPool(3) · timeout ~130s

LLaMA기술 분석
GPT시장 분석
Gemini글로벌
↓ join
GPT최종 종합 보고서 → AnalysisResult
병렬 — LLaMA(기술) · GPT(시장) · Gemini(글로벌) 동시 호출
집계 — 세 결과를 모은 뒤 GPT가 최종 종합 보고서 작성
응답은 JSON AnalysisResult(기술/시장/글로벌/최종 필드)
REST: POST /ch2/parallel-workflow · prompt
3. Routing Workflow 설명
입력을 먼저 유형(SIMPLE / COMPLEX / SEARCH)으로 나누고, 그에 맞는 ChatClient만 태우는 패턴입니다. 캐시로 같은 질문의 반복 호출을 줄입니다.

3) 맵/테이블로 모델 선택(미정 문자열은 getOrDefault로 GPT)
4) SIMPLE→Llama, COMPLEX→GPT, SEARCH→Gemini 호출
5) 응답 캐시 저장
REST: POST /ch2/routing-workflow · prompt
4. Orchestrator-Workers 설명
GPT가 계획을 짜고 최종 보고까지 맡고, LLaMA·Gemini는 Worker로 하위 작업을 병렬 처리합니다. 예외 처리와 단계 로그가 포함된 협업 구조입니다.
동작 흐름
1 · Planning (GPT)워커 지시서 · Worker_Llama / Worker_Gemini
↓

Execution · FixedThreadPool(2)

Worker · Gemini트렌드·글로벌

3 · Aggregation (GPT)최종 보고서
Planning — GPT가 작업 분해·전략 수립
Execution — LLaMA(구조·데이터 성격) + Gemini(확장·글로벌 성격) 병렬
Aggregation — GPT가 Worker 산출물을 하나의 보고서 톤으로 통합
REST: POST /ch2/orchestrator-workers · prompt
5. Evaluator-Optimizer 설명
GPT가 초안·수정(Optimizer), Gemini가 채점(Evaluator)을 맡아 글을 돌려 깎는 루프입니다. EvaluationWorkflowService 기준 최대 3회, 점수 80점 이상이면 종료합니다.
동작 흐름
GPT · Optimizer피드백 반영 초안/수정
↓
Gemini · Evaluator점수 · 점수: N 파싱
↓
판단≥80 PASS · else 피드백 루프

↺ 최대 MAX_ITERATIONS(3) · PASS_SCORE 80

1) GPT Optimizer — 작성 또는 피드백 반영 수정
2) Gemini Evaluator — 완성도·논리 등 평가
3) 응답에서 점수 파싱(예: 점수: 85)
4) 80점 미만이면 피드백과 함께 다시 1)으로(최대 3회)
5) 기준 충족 시 최종 텍스트 반환
REST: POST /ch2/evaluator-optimizer · prompt
