1. Docker 설치

Docker — Get Docker — OS에 맞는 Docker Desktop(또는 Linux의 Docker Engine)을 설치합니다. 설치 후 터미널에서 docker version으로 클라이언트와 엔진이 모두 응답하는지 확인하세요.

설치 시 주의 사항
  • Windows: Docker Desktop은 보통 WSL 2 기반입니다. BIOS/UEFI에서 가상화(VT-x/AMD-V)가 켜져 있어야 하고, WSL2 설치·업데이트는 공식 가이드를 따릅니다.
  • 리소스: Docker Desktop → Settings → Resources에서 CPU·메모리·디스크를 할당합니다. Redis는 상대적으로 가볍지만, 여러 이미지를 쌓으면 디스크가 빠르게 늘어납니다.
  • 포트: 다음 절에서 쓰는 6379가 로컬에 이미 설치된 Redis나 다른 서비스와 겹치지 않는지 확인합니다.
  • 회사망·보안: 프록시/VPN/백신이 Docker Hub 접속이나 docker pull을 막을 수 있습니다. 필요하면 IT 정책에 맞게 설정합니다.
  • 관리자 권한: 설치·업데이트 시 관리자 권한이 필요할 수 있습니다.
문제 발생 시 해결 방안
  • docker를 찾을 수 없음 → Docker Desktop이 설치되어 있고 실행 중인지(시스템 트레이) 확인합니다.
  • Cannot connect to the Docker daemon → Docker Desktop을 완전히 종료 후 다시 실행하거나 PC 재부팅 후 재시도합니다.
  • port is already allocated → 6379를 쓰는 프로세스·컨테이너를 종료하거나, 다음 절의 docker run에서 호스트 포트만 다른 값(예: -p 6380:6379)으로 바꿉니다. 이 경우 IntelliJ·애플리케이션 연결 포트도 같이 맞춥니다.
  • 이미지 pull 실패 → 네트워크·DNS·방화벽을 확인하고, 잠시 후 재시도하거나 Docker 공식 문서의 네트워크/프록시 항목을 참고합니다.
  • WSL 관련 오류(Windows) → Docker Desktop → Settings → Resources → WSL integration에서 배포판 연동을 켜고, wsl --update 등으로 환경을 점검합니다.

2. Redis 이미지 및 컨테이너 실행

Docker Desktop을 실행 후 명령 프롬프트에서 아래를 실행합니다. 컨테이너 이름은 my-redis입니다.

docker run --name my-redis -p 6379:6379 -d redis redis-server --requirepass 1234

3. Redis 서버 시작 / 중지

Docker Desktop → Containers에서 my-redis를 선택하고 Actions의 Start / Stop으로 실행·중지합니다.

문제가 있으면 컨테이너를 삭제한 뒤 이미지도 정리하고, 2번 절차를 다시 진행합니다.

4. Redis 접속 확인 (CLI)

docker exec -it my-redis redis-cli

# 접속 후 테스트
ping
# (error) NOAUTH Authentication required.
# 비밀번호 로그인
auth 1234
ping
# PONG

5. Redis와 IntelliJ 연동

IntelliJ 우측 Database → Data Source → Redis

  • Host: localhost
  • Port: 6379
  • Password: 1234

Redis 드라이버를 설치한 뒤 Test Connection으로 연결을 확인합니다.

6. Redis 운영 기본 명령어

4번으로 redis-cli에 접속한 뒤 사용합니다.

# 모든 키 조회
keys *

# 키 삭제
del testkey

# TTL 확인
ttl testkey

# Redis 정보 확인
info

# 메모리 사용량 확인
info memory

7. 컨테이너 관리 명령어

Docker Desktop으로도 제어할 수 있으며, CLI 예시는 다음과 같습니다.

# 컨테이너 상태 확인
docker ps

# 컨테이너 중지
docker stop my-redis

# 컨테이너 시작
docker start my-redis

# 컨테이너 삭제
docker rm my-redis
