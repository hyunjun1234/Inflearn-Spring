Gemini 환경 설정

Google AI Studio API 키 · 프로젝트 연결 · Spring Boot .env 연동

Gemini API는 Google AI Studio에서 프로젝트와 API 키를 만든 뒤, Spring AI 설정의 GEMINI_KEY 등과 연결합니다. 키와 프로젝트 ID는 버전 관리에 포함하지 않습니다.

목차

  1. API 키 발급
  2. Gemini 문서
  3. Spring Boot 프로젝트에 키 입력

1. API 키 발급

Google AI Studio — API Keys

  1. Projects → 새 프로젝트 생성
  2. API Keys → Create API key — 키를 만들 때 위에서 만든 프로젝트를 선택합니다.

2. Gemini 문서

Gemini API Documentation

3. Spring Boot 프로젝트에 키 정보 입력

프로젝트 루트에 .env를 두고 키를 저장합니다. Git에는 올리지 않도록 .gitignore에 등록합니다.

OPEN_AI_KEY=sk-proj-TcdDCv
GEMINI_KEY=AIzaSyDkpW5sh1I

Spring Boot가 .env를 읽도록 yml에 다음을 추가합니다.

spring:
  config:
    import: optional:file:.env[.properties]
