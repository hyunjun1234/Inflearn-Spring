IntelliJ 환경 설정

JDK 설치 · IntelliJ IDEA 설치 · 자동 빌드·인코딩·Hot Swap — 본 과정 Spring Boot 실습을 위한 IDE 준비

이 문서는 로컬 개발에 필요한 JDK와 IntelliJ IDEA 설치 링크, 그리고 저장 시 재실행·UTF-8 인코딩 등 본 저장소 예제를 따라가기 위한 최소 설정을 정리합니다. 이후 Chapter 실습은 이 환경을 전제로 합니다.

목차

  1. JDK
  2. IntelliJ IDEA 다운로드
  3. IDE 기본 설정 (탐색기·자동 빌드·인코딩·Update)

1. JDK

JDK Download (Oracle) — 프로젝트는 Java 17(Java 21 버전 사용 가능) 을 사용합니다.
설치 후 명령 프롬프트에서 java -version으로 버전을 확인하세요.

2. IntelliJ IDEA 다운로드

IntelliJ IDEA Download — Community 또는 Ultimate 중 환경에 맞는 에디션을 선택합니다.

3. IntelliJ 환경 설정

Project Explorer
Rerun as soon as you save the code (저장 시 클래스·리소스 반영)
  1. Settings → Advanced Settings → Compiler → Allow auto-make to start even if developed application is currently running ✓
  2. Settings → Build, Execution, Deployment → Compiler → Build project automatically ✓
  3. Settings에서 encoding 검색 후 전역·프로젝트 인코딩을 UTF-8로 통일
  4. Run/Debug Configurations → 해당 Spring Boot 실행 항목 → Modify options → On 'Update' action → Update classes and resources ✓
