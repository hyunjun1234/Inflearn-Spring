입력 예시 (SecurityScanner 민감 탐지·SecurityService 라우팅 — 화면 기본값과 같은 문장을 붙여 넣어 볼 수 있습니다)

  • 예시 1 · 전화번호 · 기본값 (전화 패턴 → 민감, Llama·보안 모드)
    010-2121-2211 의 전화 번호는 누구의 번호야
  • 예시 2 · 이메일 (이메일 패턴 탐지 → 민감, 외부 GPT로 보내지 않음)
    team-lead@company.example 에 보낼 주간 업무 요약 메일 초안을 짧게 작성해줘
  • 예시 3 · 기밀 키워드 (대외비·기밀 등 키워드 → 민감 처리)
    이 대외비 설계도에서 제목과 목차만 bullet로 뽑아줘
  • 예시 4 · 일반 (민감 정보 없음 → GPT 경로)
    파이썬에서 리스트와 튜플의 차이를 한 문단으로 설명해줘
